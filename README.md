# Pokédex Portfolio

Projeto de portfólio desenvolvido em HTML, CSS e JavaScript para explorar a PokéAPI e criar uma Pokédex interativa com busca por número ou navegação entre Pokémons.

## Sobre o projeto

Este projeto foi criado como uma aplicação de demonstração para portfolio, com foco em:

- consumo de dados da PokéAPI
- interface visual responsiva e simples
- navegação entre Pokémons
- exibição de tipos, imagem oficial e identificação do Pokémon

A estrutura foi pensada para ser leve, fácil de entender e de adaptar em outros projetos futuros.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- PokéAPI

## Funcionalidades

- Busca por ID do Pokémon
- Navegação para próximo e anterior
- Exibição do sprite oficial do Pokémon
- Visualização dos tipos com ícones e cores
- Background dinâmico conforme o tipo principal
- Layout com foco em portfólio e apresentação visual

## API utilizada

Este projeto consome a API pública da PokéAPI:

- https://pokeapi.co/
